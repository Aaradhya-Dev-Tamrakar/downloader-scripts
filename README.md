# Downloader Scripts

Collection of custom PowerShell and Batch automation scripts for downloading audio and video streams via `yt-dlp`.

## Included Scripts

- `yt.ps1`: Interactive or command-driven downloader script.
- `yt-music.ps1`: Audio extraction and music tagging preset script.
- `yt-video480.bat`: Fast 480p batch video download preset.
- `yt-video720.bat`: 720p HD batch video download preset.

## Prerequisites

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) placed in this folder or available on system `PATH`.
- [ffmpeg](https://ffmpeg.org/) recommended for audio conversion and muxing.
